## 🚀 Quickstart  

1. Install **Fabric 1.21** for Minecraft.  
2. Download the latest **PAPTOS release JAR**.  
3. Place it in your `.minecraft/mods` folder.  
4. Launch Minecraft with the Fabric profile.  
5. Join our community to receive your **access code**.  
6. optional use the mcpack a curated list of compatable mods with paptos 

**Basic Controls:**  
- Command Prefix: `user choice`  
- Bind Modules: Middle-click in ClickGUI  
- Toggle Modules: Assigned keybinds or direct click  

---

## ⚡ Performance Recommendations  

- Allocate **2–4GB of RAM** to Minecraft.  
- Use **Sodium-compatible shader packs** for best visuals.  
- Run on an **SSD** for faster load times and smoother chunk rendering.
